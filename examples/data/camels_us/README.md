# CAMELS-US example data

The file `01013500.csv` contains the model-ready daily series used by the
HydroSoftware demonstration for CAMELS-US basin 01013500 (Fish River near Fort
Kent, Maine).

The series was prepared from the public CAMELS-US data products, including
Daymet meteorological forcing and USGS streamflow. Users who redistribute or
reuse the source data should cite the original CAMELS-US data products and the
associated publications.

HydroSoftware uses this file only as a reproducible example dataset. The source
CAMELS-US products remain governed by their original data-provider terms and
attribution requirements.
